# Definition of Done

Un issue está `done` cuando se cumple **todo**:

- [ ] Todos los criterios de aceptación marcados como verificados por el tester.
- [ ] Build sin errores y tests en verde (comandos definidos en `AGENTS.md`).
- [ ] Sin código muerto, `TODO` sin issue asociado ni archivos temporales.
- [ ] Secciones *Implementación* y *Verificación* del issue completas.
- [ ] Decisiones relevantes registradas como ADR en `.ai/decisions/`.
- [ ] `STATE.md`, `LOG.md` y `ROADMAP.md` actualizados.
- [ ] Commit(s) según [git.md](git.md) con `Refs: #NNNN`.
